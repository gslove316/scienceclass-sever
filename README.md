# 애림쌤의 중학교 과학 교실

중학교 과학(1·2·3학년 / 물리·화학·지구과학·생물) 학습 포털입니다.
두 가지 버전이 들어 있습니다.

## 1. 간단 버전 — `index.html`

**제목: 애림쌤의 중학교 과학 교실** · 차분하고 선명한 디자인

- 파일 하나로 동작합니다. **`index.html`을 더블클릭**해서 브라우저로 열면 바로 사용 가능합니다.
- 설치·서버 불필요.
- 수업 자료는 **열어본 그 브라우저**에 저장됩니다(localStorage).
- 관리자: 자물쇠 아이콘 → 비밀번호 **`1004`** (로그인 후 변경 가능)

> 선생님 혼자 한 기기에서 쓰거나, 간단히 시연할 때 좋습니다.

## 2. 서버 버전 — `server/` 폴더

**제목: 애림쌤의 신나는 과학교실** · 아기자기하고 화사한 디자인

- 수업 자료가 **서버에 저장**되어 **모든 학생이 똑같은 자료**를 봅니다.
- **제목도 관리자 페이지에서 변경**할 수 있습니다.
- 실행: `cd server && npm start` → http://localhost:3000
- 인터넷 배포 방법은 **[`server/README.md`](server/README.md)** 참고.
- 관리자: 자물쇠 아이콘 → 비밀번호 **`1004`** (로그인 후 변경 가능)

> 학급 전체가 같은 자료를 공유해야 할 때 사용하세요.

---

### 어떤 걸 써야 하나요?

- **"일단 바로 써보고 싶다"** → `index.html` (간단 버전)
- **"학생들 모두 같은 자료를 봐야 한다 / 인터넷에 올리고 싶다"** → `server/` (서버 버전)

두 버전 모두 2022 개정 교육과정·비상교육 교과서 단원을 기본 자료로 담고 있습니다.
