# 애림쌤의 신나는 과학교실 — 서버(API) 버전

중학교 과학 학습 포털의 **서버 기반** 버전입니다.
localStorage 버전(`index.html`)과 달리, 수업 자료가 **서버 한 곳에 저장**되어 **모든 학생이 똑같은 자료**를 봅니다.
관리자가 집에서 수정하든 학교에서 수정하든 **모두에게 똑같이 반영**됩니다.

---

## 두 버전의 차이

|  | localStorage 버전 (`/index.html`) | 서버 버전 (이 폴더) |
|---|---|---|
| 자료 저장 위치 | 열어본 그 브라우저 1대 | 서버 1곳 (모두 공유) |
| 학생이 보는 자료 | 기기마다 제각각 | 모든 학생이 동일하게 봄 |
| 관리자 수정 반영 | 그 기기에만 | 모든 사람에게 즉시 |
| 실행 방법 | 파일만 열면 됨 | Node.js 서버 실행 필요 |
| 제목 변경 | (고정) | 관리자 페이지에서 변경 가능 |

---

## 바로 실행하기 (내 컴퓨터)

Node.js 18 이상이 설치되어 있어야 합니다. (https://nodejs.org 에서 설치)

```bash
cd server
npm start
```

브라우저에서 **http://localhost:3000** 접속.

- 관리자 로그인: 우측 상단 **자물쇠 아이콘** → 비밀번호 **`1004`**
- 로그인 후 **제목 변경 / 비밀번호 변경 / 항목 추가·수정·삭제·순서변경** 가능
- 수업 자료는 `server/data/store.json` 파일에 자동 저장됩니다.

> 별도 설치 패키지가 없습니다(Node.js 내장 기능만 사용). `npm install` 없이 바로 `npm start` 하면 됩니다.

## 웹에 배포하기 (인터넷 공개)

학생들이 인터넷에서 접속하려면 아래 무료 서비스 중 하나에 올리면 됩니다.

### 방법 1. Render.com (추천 · 무료)

1. https://render.com 가입 (GitHub 계정 연동)
2. 이 `server` 폴더를 GitHub 저장소에 올립니다.
3. Render 대시보드 → **New +** → **Web Service** → 저장소 선택
4. 설정값:
   - **Root Directory**: `server`
   - **Build Command**: (비워 둠)
   - **Start Command**: `node server.js`
5. **Create Web Service** 클릭 → 몇 분 뒤 `https://내서비스.onrender.com` 주소가 생깁니다.
6. 이 주소를 학생들에게 공유하면 됩니다.

> 데이터 영구 저장을 원하면 Render의 **Disk**(디스크) 기능을 추가하고 환경변수 `DATA_DIR`를 디스크 경로로 지정하세요. (무료 플랜은 재시작 시 데이터가 초기화될 수 있습니다.)

### 방법 2. Railway.app

1. https://railway.app 가입
2. **New Project** → **Deploy from GitHub repo** → 저장소 선택
3. 환경변수 `PORT`는 Railway가 자동 지정합니다.
4. 생성된 주소를 공유합니다.

### 방법 3. 학교 컴퓨터를 서버로 (교내망)

학교 네트워크 안에서만 쓸 거라면, 선생님 컴퓨터에서 `npm start` 후
같은 네트워크의 학생들이 `http://선생님컴퓨터IP:3000` 으로 접속할 수 있습니다.

## 환경 변수 (선택)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `DATA_DIR` | `server/data` | 자료 저장 폴더 (배포 시 영구 디스크 경로 지정 권장) |
